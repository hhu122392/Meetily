- 中英文设置页标题、Tab、语言选择器、通知和数据存储卡片无乱码、方框字或不可读截断；

- 证据截图下沿不包含录音目录绝对路径、会议文本、API Key 或模型配置值；
- 所有样本均未发现可见翻译键、Unicode 替换字符或横向溢出的可交互控件。

## 3. 自动可访问性检查

- 所有可见 `button`、`input`、`select`、`textarea`、链接和带交互角色的控件均能解析出可访问名称；
- `<html lang>` 与当前 UI Locale 一致；
- Locale 切换后没有记录运行时异常、控制台错误或错误级 WebView2 日志；
- `dir` 保持可审计，当前英语与简体中文均为 LTR；首期没有声明 RTL 支持。

## 4. 证据边界

本轮缩放由 WebView2 DevTools 的 `deviceScaleFactor` 模拟，用于稳定复现 CSS 布局，不能完全替代 Windows 系统 DPI、多显示器、ClearType、实体触控或 GPU 驱动差异。

以下仍为 `OPEN`：

- Windows 100%、125%、150%、200% 系统 DPI 下逐项人工操作；
- Narrator／NVDA 对中英文控件名称、状态变化、Toast、Dialog 和焦点顺序的朗读；
- 仅键盘完成设置、录音、导入、模板和摘要核心流程；
- WCAG 对比度工具扫描及高对比度模式；
- Windows Shell 托盘和系统通知的缩放与读屏表现。

因此视觉截图子项可以判定 `PASS`，完整可访问性发布门禁不能判定 `PASS`。
