# 本地实时转写

在「设置 → 录音设置」开启「实时转写」。默认关闭，保存后对下一场录音生效，录音期间不能切换。请先选择并下载本地 SenseVoice、Whisper 或 Parakeet 转写模型。

手动开始录音和指定会议号自动录音共用这个开关。自动录音仍使用群指令 `@会议助手 会议ID:550 544 175`，需要授权账号在运行 Meetily 的电脑上加入匹配的会议。

录音过程中显示本地转写预览。语音按停顿分段，连续讲话最长每八秒封一段，再加上模型推理时间后显示文字。设备和模型决定实际延迟，八秒不是文字显示时间保证。

完整音频始终保存。预览队列最多保留四段，模型过慢时后续预览可能缺段，实时模型不可用时提示错误并继续保存音频。其他后台转写占用同一本地模型时，预览需等待模型空闲。

离会后先停止并保存音频，随后后台使用完整录音进行最终转写，成功后才生成纪要。当前版本会整场重新转写，并非只处理最后几秒，因此会后处理时间仍取决于录音长度和模型速度。最终结果不会拼接预览文字，避免重复段落。转写失败保留音频和任务错误，可从后台任务重试。

实时文字只用于当前录音页面预览，重新打开页面可能丢失这部分预览，最终转写结果按原流程保存。停止后的旧结果不能更新下一场录音。发群继续人工确认。
