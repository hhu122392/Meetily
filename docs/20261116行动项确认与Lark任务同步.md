# 行动项确认与 Lark 任务同步

本功能在用户分支 `codex/summary-templates-layout-20261107` 实现，适用于当前国际版 Lark 会议助手。默认不勾选、不自动同步；不需要公司服务端，不依赖云录音。

## 使用流程

1. 生成或编辑会议纪要，在纪要工具栏点击“行动项”。程序保存当前纪要，并从完整 Markdown 的行动项章节提取候选待办。
2. 核对每条事项及“纪要原文依据”。可修改事项，或点击“补充行动项”。“保存待办草稿”只写入本机，不修改纪要正文，不创建远端任务。
3. 若会议明确提到负责人，展开“匹配负责人”，获取会议助手可访问的群，选择群后从成员中逐个选人。允许多个负责人。同名人员展示 ID 后缀，需人工核实，不按姓名自动分配。群仅用于查找人员，不发送群消息。
4. 核对截止日期。明确的 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:mm` 可以带入；“下周五”、缺少年份等保留原文，由用户确认具体日期。未提到负责人或截止时间时留空，不默认填当前用户或今天。只填日期按全天任务处理；填写具体时刻时按北京时间处理。
5. 首次同步点击“连接 Lark 任务”，在浏览器授权后返回，点击“刷新授权”。授权不改变本地录音、自动录音或发群设置，并保留已有日历及云空间授权范围。
6. 勾选需要同步的条目，点击“预览同步”。核对事项、负责人和截止时间，再勾选“我已逐条核对”，点击“确认同步到 Lark 任务”。
7. 查看逐条同步记录。成功记录提供任务链接；重新打开窗口仍保留结果，默认不勾选任何条目。

任务以当前 Lark 登录账号的身份创建，可在 Lark 任务中查看自己创建的任务；负责人为空时仍可创建。第一版不选择任务清单、不接入多维表格，也不回写远端任务的完成状态。创建任务后，Lark 自身可能向负责人发送任务通知。

## 提取范围与模板

使用本地规则解析，不额外调用模型，不把整份纪要上传到 Lark。支持“行动项”“行动项目”“待办事项”“后续行动”“下一步”“Action Items”等章节中的表格、项目列表和未完成复选框；忽略代码块、已完成复选框及其他章节。相同事项合并时保留不同负责人、日期及原文，日期有冲突时要求人工核对。

这是对纪要已明确列出的待办进行提取，不重新分析整段转写。自由叙述、非标准表格或无明确章节可能无法识别，需人工补充。纪要原文依据来自已保存 Markdown，不代表程序重新验证了录音事实。

建议在纪要模板中使用以下指令：

> 提取会议明确提出的后续事项，按“事项、负责人、截止时间”列出。负责人和截止时间只引用会议明确的信息，未提到则单元格留空，不猜测、不自动指定当前用户、不补今天。保留相对日期原文供人工确认。

| 事项 | 负责人 | 截止时间 |
| --- | --- | --- |
| 补充接口测试 | | |
| 核对发布清单 | 张三 | 2026-11-20 |

模板只控制纪要生成内容；是否创建任务必须经独立的人工确认流程。

## 新增权限与首次连接

管理员在当前会议助手应用的权限管理中申请并发布以下权限。代码支持不等于后台已经审批，本轮开发没有修改真实后台权限。

| 身份 | 权限 | 用途 |
| --- | --- | --- |
| 用户身份 | `task:task:write` | 以本人身份创建任务 |
| 用户身份 | `offline_access` | 延续已有登录，原有配置通常已具备 |
| 应用身份 | `im:chat.members:read` | 读取机器人所在群的成员，用于人工匹配负责人 |

群列表沿用现有 `im:chat:read` 配置。若只创建没有负责人的任务，不需要获取群成员。应用权限发布后，还需在 Meetily 点击“连接 Lark 任务”完成新增用户授权；仅重启软件不会自动获得任务权限。

新增权限导入文件：[行动项权限增量](./lark-action-tasks-permissions.json)。当前集成使用 `open.larksuite.com`，不会自动把国内飞书应用的凭证当作国际版 Lark 使用。

## 重复创建和失败处理

- 预览绑定纪要内容、行动项草稿、应用和登录账号，15 分钟内有效。更改事项、人员、日期或勾选范围后必须重新预览；纪要或账号在后台变化也会阻止旧预览同步。
- 每条网络请求前先保存“发送中”状态和幂等标识，成功后保存任务 ID 与链接。已成功条目不重复创建，不自动修改已创建任务。
- 遇到失败停止后续条目。平台明确拒绝的条目可修正后重新勾选、预览、确认；网络超时、异常响应或进程中断的条目标为待核对，不自动重试，也不直接允许重新创建。需先在 Lark 中核实；本版尚未提供不确定结果的人工关联恢复入口。
- 同一事项改写为完全不同的文字，或导入为另一场会议，可能成为新候选；程序不做语义去重，请核对历史任务。去重记录保存在当前电脑当前公司资料中，不是跨电脑共享锁。多人分别导入同一会议时需约定由一人负责同步。
- 保存草稿、保存云文档、发送群纪要、打开软件、连接日历都不会自动创建任务。

## 验证范围

自动测试覆盖本地提取、空值不补全、日期时区、同名人工选择、多人负责、预览失效、账号隔离、重复提交、部分失败、未知结果及重启后的阻断、关联数据删除。真实 Lark 权限、任务链接和负责人客户端展示需要授权后用测试会议验收。本轮测试不创建真实任务、不通知同事。
