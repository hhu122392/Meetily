# 纪要语言与标题修复

## 问题

后台生成纪要时，如果会议没有指定输出语言，即使已经识别出中文转写，最终处理仍可能选择英文。会议列表标题取自最终纪要首行，所以标题和正文都会成为英文。

## 调整

- 手动生成与后台生成共用语言回退规则：先使用明确指定的语言；没有指定则跟随识别出的会议语言。
- 标题与正文从同一份最终纪要提取、保存，不使用英文缓存标题替代最终标题。翻译要求明确包括首行会议标题。
- 首次安装、没有保存默认语言时，默认选择中文，并应用到新录音和新导入会议。已有明确保存的其他默认语言继续保留。
- 在设置的纪要语言中取消固定默认语言后，选择会被记住；新会议改为自动跟随会议语言，不会在重启后重新固定中文。
- 尚未能可靠识别的语言继续使用原有英文回退；可在会议详情明确选择中文或其他语言。

## 已有记录

升级不会自动重写历史会议内容。之前生成的英文会议，打开会议详情，选择中文并重新生成纪要，完成后会更新标题和正文。此操作会重新生成纪要内容，请先保存需要保留的人工编辑。

## 验证

覆盖自动中文、自动日语、自动英文、明确指定语言优先、无法识别的语言回退、中文标题与正文取自最终结果、新安装默认中文、取消默认后保持自动，以及新会议默认语言写入。

本次不增加 Lark 权限，不改变群同步和录音检查频率。
