# 云空间、知识库目录与消息模板

本版沿用用户分支 `codex/summary-templates-layout-20261107` 的纪要界面和云文档编辑功能，补充目录选择、上次保存位置和消息模板。以下操作说明替代旧文档中手工填写项目目录、直接进入发送的说明。

## 操作步骤

1. 在会议纪要工具栏点击“云文档”，编辑或预览完整 Markdown 正文及表格。“保存草稿”只保存本地文件。
2. 点击“选择云空间或知识库目录”。选择云空间时，首次点击“连接我的云空间”，在浏览器完成 Lark 授权后点击“刷新目录”；选择知识库时，直接读取会议助手可访问的知识库。
3. 点击目录逐层进入，通过面包屑返回上级；有多页时点击“加载更多目录”。云空间根目录、知识库根目录也可选择。点击“保存到此目录”只是选定位置，随后点击“创建并保存云文档”才会上传正文。
4. 保存成功后记住位置，下次打开优先选中。同一应用、同一会议、同一位置再次保存会更新已关联文档；更换位置会创建另一篇文档，不会移动原文档。个人云空间位置按授权账号隔离。
5. 默认不发送群消息。需要发送时，在“Lark 消息”勾选“需要发送到群”，再点击“发送到群”，选择群和消息模板、预览并确认。勾选本身不发送，保存文档也不发送，每次打开默认恢复未勾选。

目录只在打开选择器、进入层级、加载下一页或手动刷新时调用 API。同一次选择中返回已读层级使用缓存，不自动轮询。保存时还会检查目录、权限和文档版本。

## 消息模板

- 标准纪要：沿用结构化纪要卡片，显示会议信息、人员和概要。
- 简短通知：默认显示会议名称、时间和概要；关联云文档时另附打开文档按钮。
- 自定义模板：调整消息文字和字段顺序，填写名称后保存为常用模板。同名保存覆盖该模板，按应用和授权账号保存于本机，不同步给其他同事。

可用字段：`{会议名称}`、`{会议时间}`、`{出席人员}`、`{缺席人员}`、`{主持人}`、`{概要}`、`{云文档链接}`。字段在预览时填入，人员按行显示。没有关联云文档时，链接字段显示“未附云文档”。自定义模板按纯文本显示，暂不支持自定义卡片布局；花括号用于上述字段。

示例：

```text
【会议纪要】{会议名称}
时间：{会议时间}
缺席人员：
{缺席人员}

{概要}

完整纪要：{云文档链接}
```

模板正文最多 4000 字，展开后最多 8000 字，仍受消息卡片整体大小限制。修改模板或会议信息后，旧预览失效，必须重新预览。保存模板只写本地配置，不发送消息。消息概要与模板修改不会修改完整纪要正文。

## 权限与首次授权

本轮没有修改线上 Lark 应用权限。应用管理员需在开放平台核对、申请并发布对应权限，用户再完成授权。补充权限导入文件为 `lark-locations-templates-permissions.json`，只含本功能需要的权限；不要用它覆盖或删除已有日历等权限。

| 身份 | 权限 | 用途 |
| --- | --- | --- |
| 用户身份 | `drive:drive:readonly` | 列出本人可访问的云空间目录 |
| 用户身份 | `docx:document` | 创建、读取版本和更新个人云空间文档 |
| 用户身份 | `docx:document.block:convert` | 把 Markdown 转为文档块 |
| 用户授权范围 | `offline_access` | 获取可刷新的授权，沿用现有 OAuth 流程 |
| 应用身份 | `wiki:wiki` | 列出知识库和节点，并在指定位置创建节点 |
| 应用身份 | `docx:document`、`docx:document.block:convert` | 写入和更新知识库中的文档 |
| 应用身份 | `im:chat:read`、`im:message:send_as_bot` | 手动读取群并通过机器人发送消息 |

仅列目录可以使用 `wiki:wiki:readonly`，但本功能还要创建节点，因此需申请 `wiki:wiki`。不能只依据旧清单中细分的节点权限判断完整流程已具备权限。知识库还需授予会议助手访问权，目标容器需可创建内容；能够列出目录不代表能写入。

个人云空间使用用户身份；知识库和群消息使用应用机器人身份。现有日历登录不包含云空间所需权限，首次必须单独授权。连接云空间时，如此前已连接日历，会同时请求保留日历读取范围；以后重新进行仅日历授权，需再次连接云空间。

发文档链接不会自动修改文档共享权限，群成员能否打开取决于 Lark 中的访问设置。应用不会自动把文档设为公开。

接口依据：[云空间文件夹列表](https://open.larksuite.com/document/server-docs/docs/drive-v1/folder/list.md)、[知识库列表](https://open.larksuite.com/document/server-docs/docs/wiki-v2/space/list.md)、[知识库节点列表](https://open.larksuite.com/document/server-docs/docs/wiki-v2/space-node/list.md)、[创建知识库节点](https://open.larksuite.com/document/server-docs/docs/wiki-v2/space-node/create.md)、[创建云文档](https://open.larksuite.com/document/ukTMukTMukTM/uUDN04SN0QjL1QDN/document-docx/docx-v1/document/create.md)。

## 验收与现有限制

自动测试覆盖目录分页和缓存、授权错误、目录与账号隔离、创建接口选择、上次保存位置、模板字段校验、修改后重新预览、默认不发送及独立发送流程。真实 Lark 目录读取、权限、云端创建与更新、文档链接打开和群内实际显示仍需安装后验收；本轮未对真实群发送测试消息。

沿用上一版保护：版本冲突停止覆盖、部分保存结果未确认时停止后续写入和发送、本地草稿保留。旧版归档文档不会自动接管；不支持任意云文档导入、云端更改自动合并、实时协同或自动重命名云端标题。图片上传、合并单元格和超过 1000 个转换块暂不支持。
