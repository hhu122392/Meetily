# 文档改名与发送附件

## 本轮调整

- 云文档窗口增加“云文档名称”和“Markdown 文件名”，名称可分别编辑，不自动改写正文中的一级标题。
- Markdown 独立编辑器也可修改文件名。保存时自动补充 `.md`，保留原目录，拒绝路径字符、系统保留名称及覆盖同名文件。改名后继续编辑、重新生成和恢复历史，沿用新文件名。
- 首次创建云文档使用填写的名称，后续保存更新原文档名称与正文，保留文档链接。只改名称也会执行云端保存。云端改名或版本检查失败时保留本地草稿，不自动创建替代文档。
- “选群发送纪要”和云文档中的“发送到群”统一提供两个选项：“附云文档链接”“附 Markdown 文件”。默认都不勾选，可以只选其中一个、同时选或都不选。
- 云文档下拉列表只允许选择正文已保存并与本地一致的文档；确认发送前再次核对云端版本。未选择云文档时，普通卡片与 Markdown 附件不依赖知识库权限。
- 预览展示选中的云文档链接和 Markdown 文件名。附件只在点击最终确认后上传，以独立文件消息发往同一个群，不自动创建公开下载链接。
- 卡片和文件分别记录消息回执。卡片成功而附件失败时提示“部分成功”，停止后续操作；不会自动重试。再次发送需要重新预览并明确确认，请先核对群内消息，避免重复卡片。

## 录音配置说明

默认使用本地录音（麦克风和系统声音）。首次使用和旧配置缺少录音来源时均使用本地；已有明确保存的云录音选择保留。不会因默认值或授权操作开启自动录音。

“本地录音·手动选群”模式现在明确显示录音来源。云录音配置仍位于“群指令开会·自动关联”高级模式，切换来源需保存并重新授权。

修复连接个人云空间时把录音模式重置为本地的问题。文档授权现在保留原有录音来源、自动录音和发群设置；高级模式会一并保留其所需的会议授权范围。连接日历仍采用此前约定的本地手动会议流程。

## 权限与验证边界

第 7 项“行动项同步”尚未实现。纪要模板可以生成事项、负责人、截止时间表格，但这不等于创建飞书任务或多维表格记录。后续同步需增加人工确认、用户匹配、结果记录和防重复机制；负责人、截止时间仅使用会议明确的信息，缺失留空。

Markdown 附件沿用应用身份 `im:resource` 上传、`im:message:send_as_bot` 发消息；目标群需已加入会议助手。云空间改名使用 `docx:document`，知识库节点改名使用 `wiki:wiki`，不新增权限申请。

平台 API 权限与具体文档访问权分别检查。这个版本不会自动扩大知识库共享范围，也不会解决机器人尚未加入目标知识库的问题。

自动测试覆盖文件改名后继续保存、重新生成、路径和同名保护、附件默认与组合、预览失效、卡片与文件部分失败、云空间授权保留录音设置。真实 Lark 中的改名、附件上传和群内展示仍需安装后验收；本轮开发没有对真实会议文档改名或向群发送消息。
