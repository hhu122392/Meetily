# Mac 安装与使用说明（2026-11-07）

适用应用：Meetily 中文 Lark 定制版 0.4.1。此次构建源码为 `20f28153865ad08e5a52f0079edccc2dbbf0f155`，包含纪要模板库、界面布局调整、规则／AI 文字纠错、备份恢复及逐段手动编辑。应用内仍显示 0.4.1，请同时核对文件名、构建提交和发布批次。

## 安装包与系统要求

- 安装包名称：`Meetily-0.4.1-Mac-AppleSilicon-20f2815.dmg`。
- 芯片：Apple Silicon，即 M 系列；此包不适用于 Intel Mac。
- 系统：macOS 14.4 或以上。
- 模型权重需在安装后下载；安装包不包含任何公司的密钥、账号令牌、录音或会议数据库。
- 发布入口：[2026-11-07 定制版发布页](https://github.com/hhu122392/Meetily/releases/tag/v0.4.1-lark-20261107)。以发布页实际附件和校验记录为准。

## 安装与升级

1. 先结束录音、保存编辑并确认后台任务状态，退出旧版 Meetily。升级时保留现有应用数据和录音目录。
2. 下载 DMG，打开后将 `meetily.app` 拖到“应用程序”。已有同名应用时按公司部署流程替换程序。
3. 从“应用程序”启动。当前包使用临时签名，没有 Apple Developer ID 签名与公证；若系统拦截，由本人或公司 IT 按本公司的安装策略处理。构建签名完整性检查不代表 Apple 公证。
4. 在首次设置中选择或下载转写模型，配置纪要模型和录音保存目录。
5. 本机录音按 macOS 提示授予麦克风、系统音频／屏幕录制权限；云录音模式通过 Lark 下载文件，无需在本机采集会议声音。

## Lark 接入

使用 [权限申请清单](./Lark权限申请清单.md) 和 [配置及变更说明](./Lark与Meetily配置及变更说明.md)，由目标公司配置自己的应用、权限、事件与回调。Mac 与 Windows 的回调地址都是 `http://127.0.0.1:18576/lark/callback`。

Windows 的加密凭证不能直接迁移到 Mac 使用。请在 Mac 的正确公司资料中重新填 App ID／App Secret，再点“授权会议助手”。Mac 的本机凭证加密密钥保存在登录钥匙串；不要删除钥匙串后期待旧凭证仍可解密。

同一 Lark 应用只保留一个主要在线处理实例。切换到 Mac 负责处理时，退出另一台电脑的 Meetily 或关闭其企业应用连接；两边的 Lark 客户端可以继续登录。

## 新功能入口

| 功能 | 入口 |
| --- | --- |
| 管理纪要模板 | 设置中的纪要模板管理，或会议右上角模板菜单 |
| 按模板重新生成 | 选好会议模板后点击“重新生成纪要” |
| 编辑纪要与保存 Markdown | 纪要右上角图标工具栏 |
| 编辑或发送 Lark 消息 | 同一工具栏，发送前仍须预览并确认 |
| 规则和 AI 纠错 | 转写区域“优化转写 → 转写文字纠错” |
| 手动修改某段转写 | 鼠标移到段落，点击右侧铅笔，修改后保存；支持 Ctrl+Enter 或 Command+Enter |
| 查看转写备份 | 文字纠错中的历史转写版本入口，恢复需确认 |

手动编辑和纠错会保存转写并保留备份，不会直接改写已经生成的纪要；需要时重新生成。AI 校对只在手动点击时运行，使用当前选择的模型。

## 验收边界

本次在 Windows 上完成相关功能测试与客户端界面验收；Mac 安装包由 macOS 云端运行器构建。发布时核对构建状态、架构、DMG 和应用签名完整性。真实 Mac 的录音权限、音频采集、模型推理、钥匙串与 Lark 授权／发群仍需按配置文档实机验收。

建议先用一个测试群完成短会，确认本机或云录音、转写、纪要、文字编辑、重启读取和人工确认发送后，再用于正式会议。
