# Lark 后台辅助导入

在 Meetily 设置的「Lark 会议助手」中展开「后台辅助导入（免手填）」。

1. 点击「打开 Lark 后台」。用有应用管理权限的账号登录，选择会议助手，进入「凭证与基础信息」。已有 App ID 时会直接打开该应用的凭证页。
2. 点击后台 App ID 旁的复制按钮，回到 Meetily 点击「读取剪贴板」或在粘贴框按 Ctrl+V（Mac 为 ⌘V）。然后对同一应用的 App Secret 重复一次。已有正确 App ID 时只需补密钥，也可一次粘贴带 App ID、App Secret 标签的两项内容。
3. 选择「本地录音 · 手动选群发送」，启用会议助手，核对配置后点击「保存并连接」。此模式不需要会议 OAuth 授权或云录音权限。

复制密钥请使用后台的复制按钮；直接选中星号复制不会得到真实密钥。

导入只填入当前表单，保存后才沿用现有加密存储。切换 App ID 会清空待保存的旧密钥，导入不会自动开启录音或发群。程序仅在点击「读取剪贴板」时读取剪贴板，不监听浏览器或后台读取剪贴板；读取不可用时仍可手动粘贴。

该功能辅助导入已有权限范围内的应用凭证，不会让普通员工登录后自动获得应用管理权限，也不提供免密钥的集中服务。没有后台权限的同事仍需管理员协助初次配置；应用密钥代表机器人的应用权限，不是个人账号的权限。不要把共享密钥打包进安装程序。

手动选群及本地录音的操作和验收范围见 [本地会议流程](LOCAL_MEETING_WORKFLOW_ZH.md)。
