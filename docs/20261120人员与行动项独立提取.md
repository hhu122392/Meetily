# 人员与行动项默认提取

生成纪要时，出席、缺席人员和行动项默认独立整理，不依赖模板是否包含对应栏目。模板只决定纪要正文的结构。

- 人员继续从明确的出席、缺席表述识别，未提到的留空；不会把常用名单、邀请名单或被提到的人直接算作出席。人工修改和主动清空的名单保持不变。
- 行动项使用当前纪要模型直接分析转写，长文本分段处理。每条保留转写原文依据，负责人和截止时间没有依据时留空。模型返回格式错误或无法核对原文时，生成明确报错，不把未完成提取显示为“没有行动项”。
- 行动项独立保存在会议生成结果中，并建立本地待办草稿；编辑纪要正文不会删除独立结果，重新打开面板不会覆盖已有草稿修改。
- 只有模板包含相应栏目时才要求模型写入纪要正文。内置中英文“标准会议纪要”增加参会人员栏目，并调整行动项要求。自定义模板不会被覆盖。
- 完成生成后自动刷新人员设置。行动项面板默认不勾选，只有预览并人工确认才创建 Lark 任务；生成、保存和发群不会创建任务。
- 历史会议没有独立提取结果时，继续支持从已有纪要提取，也可重新生成纪要启用新流程。

独立行动项提取会增加纪要模型调用与耗时，不增加 Lark 权限。当前变更不包含安装或历史会议批量重新生成。
