# 三项实用功能移植说明

本次在 `codex/lark-desktop-20261103` 分支移植三项功能，保留现有中文、Lark、公司隔离和 Markdown 审核流程。参考仓库另一条 0.4.4 定制路线的功能设计，按当前架构实现；没有合并或覆盖 `main`，也没有整体引入其模板系统与存储结构。

## 长任务状态

移除前端累计轮询 200 次后自行报告“15 分钟超时”的逻辑。生成状态继续以本机后台任务实际返回结果为准，完成、真实错误和取消仍按原流程处理。轮询是本机 IPC，不新增 Lark API 调用。后端模型请求自身的超时限制不因此取消。

## 会议设置与生成快照

会议详情顶部新增“会议背景与人员设置”，可以填写出席人员、缺席人员、主持人并保存。背景仍在原背景输入框编辑，模板仍通过原模板入口选择。点击生成或重新生成时会保存这些设置；再次打开同一会议可恢复设置。

设置保存在当前公司的会议数据库中，不在会议之间或公司之间共享。每次生成另存输入与已解析模板的快照，生成过程中修改设置不影响已经启动的任务。人员名单只作为背景，不用于声纹识别或自动绑定发言人。

新增迁移文件 `20261103000000_meeting_summary_settings.sql`，增加两张表，不删除原会议或纪要数据。旧会议尚无设置时使用默认模板及空白背景，不尝试猜测历史输入。

## Markdown 历史版本

在“编辑 Markdown 文件”中点击“历史版本”，选择版本后可查看内容。点击“恢复此版本”后还需确认；存在未保存编辑时应先保存。

恢复前校验当前文件与历史文件是否变化，备份当前文件后才恢复选定内容。历史文件只能通过当前公司该会议记录指向的目录访问，拒绝目录穿越，并限制读取大小。恢复仅修改详细 Markdown 文件，不替换页面纪要编辑器或已编辑的消息草稿，也不会发送到 Lark。发群仍需走原发送预览和确认流程。
