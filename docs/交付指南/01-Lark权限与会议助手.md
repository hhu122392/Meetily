# Lark 权限与会议助手

本指南对应当前代码实现，不表示某个公司的权限已经开通。使用国际版 Lark 开放平台；不要直接换成中国飞书的域名或应用凭据。

## 管理员一次配置

1. 在 [Lark 开放平台](https://open.larksuite.com/app) 创建或选择企业自建应用，启用机器人能力，设置为同事可使用的范围。
2. 在权限管理中按下表申请权限，也可导入本目录的 `Lark权限导入.json`。导入文件是本指南全部可选能力的合集，不需要的云文档、任务或附件能力可删除对应权限。
3. 在应用安全设置中配置 OAuth 重定向地址：`http://127.0.0.1:18576/lark/callback`，大小写和路径保持一致。回调由当前电脑 Meetily 接收，无需公司服务端。
4. 创建应用版本，提交发布并完成管理员审批。保存权限、审批通过、版本生效是不同步骤，需确认实际已发布版本包含新增权限。
5. 把会议助手加入测试群，确保使用者本人也在群内。由管理员协助导入 App ID 与 App Secret，再由各同事登录自己的 Lark 账号。

普通账号登录不能自动取得开发后台 App Secret。辅助导入用于减少手工填写，不会绕过开发后台权限。不要把真实密钥写进指南、源码、截图或共享配置文件。更换电脑后重新登录，Windows 和 Mac 加密凭据不能直接互拷。

## 权限清单

| 能力 | 应用身份权限（tenant） | 用户身份权限（user） |
| --- | --- | --- |
| 发现共同群、读取指令、入会检测及指令回执 | `im:chat:read`、`im:message:send_as_bot` | `im:chat:read`、`im:message:readonly`、`im:message.group_msg:get_as_user`、`vc:meeting.meetingevent:read`、`vc:meeting`、`offline_access` |
| 解析日程分享邀请 | 无额外应用权限 | `calendar:calendar.event:read` |
| 发送 Markdown 文件附件 | `im:resource` | 无额外用户权限 |
| 云空间目录及文档保存 | 无额外应用权限 | `drive:drive:readonly`、`docx:document`、`docx:document.block:convert`、`offline_access` |
| 知识库目录及文档保存 | `wiki:wiki`、`docx:document`、`docx:document.block:convert` | 无额外用户权限 |
| 创建 Lark 任务；从群成员中匹配负责人 | `im:chat.members:read` | `task:task:write`、`offline_access` |

基础实现的授权代码见 `frontend/src-tauri/src/lark/oauth.rs`，各模块权限 JSON 在上级 docs 目录。本地录音流程不要求云录音、妙记媒体下载权限；本指南没有把旧的云录音权限列为前置条件。

## 每位同事配置

进入设置中的 Lark 会议助手，选择“同步群会议”，本人登录授权，启用本地自动录音并保存。默认自动发现本人和机器人共同加入的群；也可切换手动范围。群列表约五分钟更新，群消息每轮至少十五秒，群多、翻页或网络错误会延长等待。无需每台电脑建立机器人事件长连接，也不部署统一服务。

在实际群聊中选择机器人产生真正的 @，再发送（示例号码需替换为实际会议号）：

```text
@会议助手 会议ID:123 456 789
```

也支持官方视频会议入会链接或包含会议号的完整邀请。日程分享链接只有在本人可访问的日历中唯一解析出会议时才能绑定；解析不了时改发九位会议号。发送者的电脑负责即时回执；回执不代表其他同事的电脑已同步成功。本人进入指定会议后本机录音，确认离会后停止。要自动生成纪要，还需打开会后自动生成选项并配置可用模型。

绑定有效期为六小时；离线超过十分钟、退出后开始下一场会议等情形请重新发指令。首次启动不重放旧指令。同一账号只在一台电脑开启自动录音；检测依据是账号参会状态，不能区分该账号是否在另一台设备入会。请在运行 Meetily 的电脑参加会议，并检查本机录音状态。

云文档保存和发送到群是两步。发送窗口自动加载群；存在唯一且有效的关联群时默认选中，否则需要选择目标群。附件、已保存的云空间链接、知识库链接按需勾选，预览确认后发送。行动项默认不勾选、不自动同步。

## 授权有效期与排错

令牌期限采用 Lark 实际返回的 `expires_in`；程序在临近过期时尝试续期。管理员撤销权限、刷新令牌失效或账号变更后，需要重新授权。不能承诺登录永久有效。

| 现象 | 核对方法 |
| --- | --- |
| 没有群或指令无反应 | 检查账号、机器人是否在群内、实际 @、应用版本、用户消息读取授权；查看“最近群指令”及本机同步状态 |
| 后台已审批，客户端仍报缺权限 | 核对已发布版本，再重新连接对应功能；新增用户权限需要本人重新同意 |
| 知识库没有目录 | 区分空目录和接口错误；应用权限不等于资源访问权，需管理员给应用实际知识库访问权；本人浏览器能打开不代表应用能读写 |
| 云空间目录缺失 | 核对登录账号的目录访问权及文档授权；先在有编辑权限的测试文件夹保存 |
| 负责人无法匹配 | 核对 `im:chat.members:read` 已发布、机器人所在群和人员重名；不默认把登录者当负责人 |

官方参考：[读取群消息](https://open.larksuite.com/document/server-docs/im-v1/message/list)、[知识库概述](https://open.feishu.cn/document/server-docs/docs/wiki-v2/wiki-overview)、[任务权限](https://open.larkenterprise.com/document/task-v2/overview)、[文件资源权限说明](https://open.feishu.cn/solutions/detail/ticket?lang=zh-CN)。中国飞书页面仅用于同类接口说明，部署域名仍以国际版 Lark 为准。
