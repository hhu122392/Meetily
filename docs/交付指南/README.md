## 给协助安装的 AI

先核对系统和芯片、现有 Meetily 数据目录、安装包哈希及源码提交。询问管理员提供本公司的 Lark 应用信息，并让使用者本人完成登录。安装包、代码和示例不包含任何公司的 App Secret、令牌、会议记录或模型 API 密钥。

已有安装先退出程序并备份配置和数据库；不要删除模型、录音或旧记录，不要把发送者电脑的凭据复制给同事。没有权限时明确指出缺失的是应用权限、个人授权、资源访问权还是机器人群成员关系，不应通过修改数据库伪造成功。

首次验收使用测试群和短录音，确认双方声音、转写、纪要、保存位置和发送预览。创建真实云文档、发群消息、创建任务需按用户授权操作；测试通过后再开启日常自动录音。云端构建通过不等于真实 Mac 麦克风和系统音频已经验收。

## 本轮修复

- 行动项提取每个分片最多尝试两次；仍失败时继续生成纪要，并保存独立警告。取消生成仍然退出。
- 长原文依据可以保存，人工不能改写依据；草稿保存不会因为旧的 1,500 字限制而失败。Lark 任务描述附最多 2,000 字依据节选，完整依据保留在本机。
- Mac 辅助程序使用独立构建目录，避免与主程序打包时的辅助程序目标文件冲突。
