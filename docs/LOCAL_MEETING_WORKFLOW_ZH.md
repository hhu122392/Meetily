# 本地会议流程与验收范围

已增加 Lark 周期日程同步入口，操作见 [周期日程 → 本地录音](LARK_CALENDAR_LOCAL_ZH.md)。普通本地录音仍可独立使用。

## 日常操作

首次配置后，每场会议按「手动录音 → 生成纪要 → 核对 → 选群发送」操作。无需常开服务主机、会议号、云录音下载或 webhook。转写和纪要模型需要在设置中选择本地模型；录音方式不会自动切换已有模型设置。

1. 设置中选择「本地录音 · 手动选群发送」，导入会议助手凭证并保存。此模式关闭 Meetily 的自动录音、自动发群及机器人开会指令，不订阅长连接事件。已有自动模式配置保持原值，需主动切换并保存。
2. 手动开始录音，确认麦克风和系统声音均有输入。停止后，录音保存在本机，按现有流程生成转写和纪要。操作系统录音权限、设备选择和对方声音仍需实际通话验证。
3. 在会议背景中选择模板，首次填写出席、缺席及主持人并「保存为常用名单」。之后点击「带入常用参会人」，再把本次缺席人员移到缺席栏。不会在切换模板时覆盖当前名单，同一人不能同时出席和缺席。
4. 纪要生成后点「选群发送纪要」。核对目标群、会议名称、北京时间、人员和概要，预览后确认发送。默认只发概要卡片；完整纪要保存在本地 Markdown。日期显示为 `YYYY-MM-DD HH:mm`，缺席人员逐人换行。历史导入录音的日期必须人工核对。
5. 如需完整云文档，首次设置项目名和知识库目录链接，以后选项目即可。确认发送时创建完整文档并附链接；创建或写入失败时不发群。云文档与云录音是两个独立功能，归档不会上传录音。

## 权限和多人使用

手动发群需要应用机器人发消息、读取群信息的权限，机器人须已加入目标群。每台电脑独立录音、选群，不接收群开会事件；无需集中常开电脑。普通用户登录无法获取 App Secret，后台辅助导入仅减少输入步骤，首次仍需应用管理员协助。

归档还需要文档创建/编辑、知识库节点创建/读取及目标目录访问权限。群成员的文档阅读权限由知识库管理，发链接不会自动放开权限。当前代码只接受 Lark 的知识库目录链接，未实现飞书国内域名切换。云文档保留标题和段落；复杂 Markdown 表格、列表保留文字，不保证还原原排版。

辅助导入、项目映射和名单按本机公司资料保存，不自动分发到同事电脑。共享应用凭证的电脑拥有该应用授予的权限，不能视作按员工账号隔离。

## 发送与失败处理

预览不会发群或创建文档；实际发送核对配置、原纪要和群名称是否变化。发送结果不明确时不自动重试，先检查群消息后再确认。相同已成功发送的内容会复用结果。文档创建/写入中断时保留状态阻止自动重复建文档；部分写入的文档暂不支持自动续写，需要人工核对处理。

切换本地模式不会修改 Lark 客户端自身的自动录制设置，也不会删除已有录音或取消已排队的历史任务。Lark 自动录制开关需要在客户端单独检查。
