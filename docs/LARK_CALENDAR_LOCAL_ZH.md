# Lark 周期日程 → Meetily 本地录音

> 2026-11-18 已停用日历功能。首页近期会议、日历刷新设置、日历授权及日程录音入口均已撤下。当前使用群指令 `@会议助手 会议ID:550 544 175` 指定会议号，开启本机自动录音后，授权本人入会开始、离会停止。下文保留为历史设计说明，已有录音的日程关联信息仍可查看。

## 日常操作

1. 在 Lark 主日历创建日程，设置周期规则并邀请同事。改期、取消也在 Lark 操作。
2. 打开 Meetily 首页「近期会议」，找到本次会议。点击「加入会议」打开 Lark，再点击「开始本地录音」。两个按钮分别操作，加入会议不会自动开麦。
3. 录音结束后按原流程后台转写和生成纪要。在会议详情的「会议背景与人员设置」核对邀请名单、实际出席和缺席；可点击「带入邀请名单并核对」，将未参会人员移到缺席栏。
4. 核对纪要，点击「选群发送纪要」，选择群、预览并确认。需要完整云文档时再选择归档项目；录音不会因此上传。

日历同步、打开会议链接和录音结束都不会自动发群。生成纪要采用当前已配置的模型；如需全过程本地处理，请选择本地转写和纪要模型。

## 首次连接

- 先在设置中完成会议助手凭证辅助导入并保存，回首页点击「连接我的 Lark 日历」。
- 管理员需给应用开通并发布用户身份 `calendar:calendar.event:read`（读取日程）及 `offline_access`（离线访问）权限，并配置已有本机回调地址 `http://127.0.0.1:18576/lark/callback`。
- 日历授权成功后启用本地手动模式，关闭 Meetily 的自动录音、自动发群及机器人开会指令。不申请云录制、妙记下载、会议控制或日历写入权限。
- 发群仍需机器人读群和发消息权限，并把机器人加入目标群。日历授权不能替代应用凭证导入。
- Lark 客户端自身的自动录制开关需单独关闭。本功能不修改 Lark 日程或会前录制设置，也不取消此前已创建的历史云录音任务。

## 同步范围及周期会议

当前读取登录用户的主日历，范围为最近一天至未来 14 天。每次启动软件进入首页时同步一次，切回窗口或返回首页不会重复触发启动同步。设置中的「Lark 会议助手」提供「自动刷新日历」开关，默认关闭并记住本机选择；开启后，停留首页期间每 5 分钟同步，也可随时点「刷新日程」。首次连接个人日历成功后会同步一次，不受开关影响。共享日历中仅共享给你、未进入主日历的事件暂不包含在内；没有自动扫描全部公司日历。

使用 Lark 的日程实例视图读取周期会议的每一次，保留远端实例标识及系列信息，不由 Meetily 重新计算重复规则。同一会议号的两次会议独立保存录音、纪要及发送记录。再次录制同一次日程也会生成新的本地会议，不覆盖原文件；列表提供「查看已有录音」。

开始录音或打开日程链接前再次读取原实例所在的时间范围。若日程被取消、改期、改名、变更链接或账号已切换，停止当前操作，提示重新同步。该检查需要联网；无法核验时仍可用原来的普通手动录音入口录制，但不会自动关联日程。

同步失败时保留上次缓存并标明错误，暂停本次运行期间该账号的自动同步，手动刷新成功后恢复；不把旧列表当作已同步成功。接口成功返回的空日程列表（包括省略可选列表字段）正常显示为「暂无日程」；异常的响应结构仍报错，不清空缓存。同步完成只替换当前应用及当前账号的待开日程；历史录音关联快照不会被日程的后续修改或取消覆盖。

邀请名单不是出席名单。记录邀请信息用于核对，但不会自动填成实际出席，也不会根据接受/拒绝邀请推断缺席。名单读取失败、姓名缺失或名单过长时给出提示，允许手动填写。会议详情同时显示计划时间；发群时间默认取实际本地会议记录，可人工修正。

## 验证边界

代码具备周期实例隔离、取消与改期校验、缓存替换、账号隔离、邀请名单人工带入及手动发群流程。首次使用仍需真实 Lark 授权和一次通话验证，尤其是当前租户的日历权限、实例响应、双方声音和群内消息效果。

本次未自动更改后台权限、创建日程、启动实际录音、发送真实群消息或安装新版客户端。
