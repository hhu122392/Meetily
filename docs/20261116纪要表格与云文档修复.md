# 纪要表格与云文档修复

## 使用方式

1. 纪要工具栏点击“编辑纪要”，默认打开 Markdown 排版预览，表格直接显示为表格；点击“编辑源码”修改，切回预览即可检查尚未保存的内容。
2. 工具栏点击带文字的“云文档”，选择目标群和归档项目。
3. 首次没有项目时自动展开配置：填写项目名称，粘贴项目知识库目录链接，保存后自动选中。以后直接选择该项目即可。
4. 核对会议名称、北京时间、出席、缺席、主持人和消息概要，预览后点击确认发送。确认时才创建完整云文档，并把链接随概要卡片发送到所选群。
5. 发送成功后可点击“打开已归档云文档”。普通“选群发送纪要”入口仍允许只发概要卡片。

## 内容来源和限制

- Markdown 排版预览与源码使用同一份内容，支持表格、标题、列表和文本强调。
- 纪要面板和单独编辑的 Markdown 文件并非双向同步。文件编辑不会回写面板；云文档使用文件全文和发送窗口核对的会议信息。现有文件版本保护、冲突检测保持不变。
- 云文档改用 Lark 官方 Markdown 转块和嵌套块接口，保留表格、单元格和文本样式，不再把每行表格写成普通段落。
- 当前一次最多 1000 个内容块，表格、单元格及单元格中的文本均计数。超过限制会在创建文档前停止，不截断。
- 当前不上传图片素材，也不处理合并单元格；检测到时明确报错，不生成缺内容的文档。Markdown 预览不加载远程图片、不执行内嵌 HTML。
- 转换失败不会创建文档或发群；文档写入状态不确定时保留记录并阻止自动重复创建。群成员仍需知识库或文档访问权限。

## 权限补充

使用应用身份（tenant_access_token），本次完整排版写入需要核对：

| 权限标识 | 用途 |
| --- | --- |
| `docx:document.block:convert` | 将 Markdown 转换成文档块，包含表格 |
| `docx:document` | 通过嵌套块接口写入完整文档 |
| `wiki:node:read` | 核对项目目录 |
| `wiki:node:create` | 在目录下创建云文档节点 |
| `im:chat:read` | 读取机器人可见群 |
| `im:message:send_as_bot` | 由机器人发送概要和链接 |

以上是本流程涉及的权限，不表示当前应用已经全部开通。此前清单中的 `docx:document:write_only` 不作为本次嵌套块接口已授权的证据，需要按后台实际支持情况核对 `docx:document`。权限配置后需发布生效，会议助手还必须能够访问目标知识库并加入发送群。本次代码修复未修改后台权限，也未向真实群发送消息。

本次新增的两项文档权限见同目录 `lark-cloud-document-permissions-addition.json`；这是增补清单，不能用来替换或删除应用原有权限。

## 验证范围

自动测试覆盖 Markdown 表格预览、转义竖线、未保存内容切换、保存冲突和历史恢复；云文档入口、项目必选、保存配置、预览不发送、明确确认发送及归档目标缺失时停止；后端表格树、文本样式、只读字段清理、循环或缺失块、图片及超限拒绝。

真实 Lark 权限、目录归档和群内链接打开情况仍需实际验收。安装包构建成功与真实群发送成功分别记录，不互相替代。
