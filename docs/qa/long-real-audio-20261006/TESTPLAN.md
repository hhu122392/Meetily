## 测试范围

本轮只做测试，不修改生产代码。沿用当前分支和已有 Windows 客户端，不建 worktree。

- 来源：[2024-12-05 行政院第3929次院会后记者会](https://www.youtube.com/watch?v=7ppBEcZDit4)，官方频道“行政院開麥啦-2”，完整视频 1696.021 秒（28 分 16 秒），正常速度播放。
- 下载音轨与视频均返回 HTTP 403；浏览器实际播放成功，因此改由 Meetily 桌面“麦克风 + 系统音频”录制完整视频。录音开始时麦克风静音量，系统音频已收到声音。网络停顿、首尾等待与录音长度另作记录，不当成源视频内容。
- 模板：standard_meeting；无人员名单预设、无补充背景、无转录注入。转写设置 sensevoice / sensevoice-small-int8；摘要设置 builtin-ai / qwen3.5:4b。
- 此视频无可用字幕。独立对照使用当日官方议案与新闻稿，不把 Meetily 转录本身当事实标准；没有独立证据的问答内容标记未核验，不编造总体准确率。
