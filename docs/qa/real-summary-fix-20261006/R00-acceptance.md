# R00 基线建立验收

2026-10-06；只建立基线，不表示摘要功能已经修复。

- 桌面实测：实际 Windows Meetily 程序打开真实长音频会议，界面有 8 个待核对字段，正文仍有乳品/屋顶问题写入医疗段落，以及把修订期限扩大为核定期限。截图、原文依据、保存摘要和生成 ID 对应，证据另存本机 R00/001-baseline 与新鲜复核。
- 本机冻结：24 场会议；15 个摘要进程；70 个生成历史；30 个人工修订；123 段数据库转写；1086 个录音目录文件。SQLite 在线只读备份与逐文件 SHA256 已保存本机，不上传完整数据库和私人原始数据。
- 旧行为回放：8/8 与旧错误结果一致。修复期望回放：18 项中 13 项通过、5 项失败。失败是实际全文回放、口语期限、任务改写、要求式分工、共同负责人；没有把诊断程序执行成功当成产品通过。
- 实际全文回放改用 SenseVoice、无会议上下文，并保留 62 个原始片段的 ID/时间/文字。短句对照明确标为构造用例，不冒充真实 ASR。
- 32 项事实在产品修改前分类冻结；Q09/Q12/Q27 仍无口述证明。明确责任、期限、前提、行动和关键范围为必需；其他细节单列。姓名组接受可靠词典对照或明确未核验，不偷偷把标准答案放入默认模型输入。
- Review：原始音频、转写、模板及旧摘要未修改；实际长样本仍失败；反例包含不同任务、否定、假设、接收人、匿名第一人称和撤回期限。后续任务必须检查这些反例无 false_supported。

结论：R00 基线准备通过。R01–R08 尚未验收。
