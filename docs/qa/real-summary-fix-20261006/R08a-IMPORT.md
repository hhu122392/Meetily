## 原因与修改

桌面选择 SenseVoice 后，导入后端只分 Parakeet 与 Whisper 两路，把 SenseVoice 请求送到 Whisper，并写入错误的引擎记录。共用入口现按所选引擎分流，沿用 SenseVoice 现有语言校验和转写实现；加载请求的模型，保存实际引擎、模型与语言。未知引擎直接报错，避免静默替换。保持现有目录保护、取消机制与 Parakeet 的自动语言限制。
