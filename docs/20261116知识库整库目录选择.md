# 知识库整库目录选择

在用户分支 `codex/summary-templates-layout-20261107` 补充。云文档保存和发群仍然分开，选择目录本身不会创建文档或发群。

## 操作

1. 在云文档窗口打开“选择云空间或知识库目录”。上次保存位置和已保存目录可直接使用，不必再从根目录寻找。
2. 选择一个知识库，点击“一键加载本知识库全部目录”。
3. 等待加载完成后，在目录树上点击目标目录；也可以输入目录名或路径片段搜索，直接选择深层目录。
4. 核对上方完整路径，点击“保存到此目录”，返回云文档编辑窗口后再保存文档。

整库加载仅用于当前选中的知识库。云空间保留逐级选择，已保存的云空间位置同样可以快速复用。系统不会在打开软件时扫描所有知识库。

## 速度与接口调用

- 原界面每次打开都会清空浏览缓存，现在同一组件内重开保留缓存，账号或应用凭证变化时清理。
- 一次操作加载不等于一次 API 调用。Lark 提供的是子节点分页接口，后台需要按层级和分页继续读取；已明确没有子节点的目录不会再请求子目录。
- 同一次整库加载复用应用访问凭证，不在每层重新获取凭证。加载过程中显示已发现目录数和请求页数，并可取消正在等待的请求。
- 成功加载的完整结果保存在当前公司本机数据库，按应用、账号、凭证与知识库隔离，30 分钟内复用。点击“刷新全部目录”会重新读取。
- 搜索、展开已加载结果、显示更多搜索结果及读取加载进度只访问本地，不调用 Lark API。选择保存位置及实际保存文档仍会重新核对访问权限。
- 每次最多读取 200 页、5000 个节点，展开深度不超过 50 层。达到上限、取消、分页异常或权限失败会停止请求，显示“部分目录”及原因；可选择已读取目录，或继续使用逐级浏览。
- 部分结果只在当前窗口展示，不会覆盖上一次成功的完整缓存。全量加载可能比只找一个已知目录消耗更多接口调用；已保存位置直接复用最快。

## 验证范围

测试覆盖分页空页继续加载、叶子节点不重复请求、深层路径直接选择、搜索不联网、取消、权限失败保留部分结果、分页循环保护、请求上限、账号缓存隔离及最近位置复用。尚未用真实大型知识库进行耗时测试，不宣称实际加载秒数。知识库访问权仍由 Lark 控制。

接口依据：[获取知识空间子节点列表](https://open.larksuite.com/document/server-docs/docs/wiki-v2/space-node/list)。
