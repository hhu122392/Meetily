# Meetily 0.4.3 — Windows x64

社区构建，2026-09-14。

本版修复了新安装默认落到 Parakeet、SenseVoice 页面误显示 Whisper `small` 下载入口的问题。SenseVoice 现在是前端和原生后端共同的无配置默认值；SenseVoice 未下载时，导入和重转写页面不会偷偷切换到其他模型。Whisper 改为按需初始化，默认启动不再加载 Whisper 原生运行路径，降低旧 Whisper 配置在不兼容 CPU 上触发闪退的机会。

下载安装 `Meetily-0.4.3-windows-x64-setup.exe`。安装包自带 WebView2、VC++、ONNX/sherpa 运行库和辅助程序；不需要开发工具。首次启动请在 SenseVoice 模型卡片点击下载，模型、个人会议和 API 密钥不在安装包中。

本构建未使用 Authenticode 发布者签名，Windows 可能显示未知发布者。请核对同版 SHA256SUMS.txt。

已知限制：用户主动选择的 Whisper 模型仍受本机 CPU 指令集影响；本版避免默认启动 Whisper，但没有把所有旧 Whisper 模型自动迁移到 SenseVoice，以免覆盖用户明确选择。重要转录和摘要仍需人工复核。
