# Meetily 0.4.4 — Windows x64

社区构建。

本版修复会议设置、摘要生成和模板升级中的问题：

- 录音前选择的会议模板及出席、缺席、主持人信息会随会议保存，并用于摘要；导入音频沿用本次会议设置。
- 摘要中已有的负责人、期限等字段，不再因为程序未找到逐字匹配的原文而被清空。程序未核实的内容仍保留核对状态。
- 默认标准会议模板的行动表保留负责人、任务和截止时间，摘要正文不再要求附录音时间戳与来源列。自定义模板继续使用自己的业务字段。
- 升级只更新内容与旧版内置文件一致的标准模板；保留用户修改、导入、删除状态与模板原语言，并备份被更新的模板。
- 补充背景随本次生成请求使用；录音期间模板锁定原因更清楚；编辑器菜单跟随界面语言；长任务结果与人工编辑历史保留。
- 音频导入正确使用所选 SenseVoice 引擎；侧栏版本号与安装版本一致。
- 更新编辑器粘贴相关依赖，修复上游已确认的安全漏洞；修正中文复合数字期限的错误等同判断。

下载 `Meetily-0.4.4-windows-x64-setup.exe` 安装。已有 v0.4.3 用户直接运行新版安装包升级，升级前会备份应用核心数据。安装包内置 WebView2、FFmpeg 和必要运行库；首次使用仍需下载转写/本地摘要模型，或配置自己的摘要 API。

此社区构建没有 Authenticode 发布者签名，Windows 可能显示未知发布者。下载后可与同页 `SHA256SUMS.txt` 核对。自动更新未启用。

准确性边界：语音识别人名、专有名词、数字仍可能出错；更换摘要模型不能保证纠正转写错误。本轮真实长会议仍出现正文保留条件、英文自定义表格依赖列却填写“未提及”的情况，正文也可能省略限定词。这些结果问题尚未完全解决。程序的“尚未核实”不代表字段一定错误，也不代表已验证正确。重要会议仍应对照录音复核，本版不宣称所有摘要事实均已准确。

发布验收记录见 [v0.4.4-validation.md](https://github.com/hhu122392/Meetily/blob/main/docs/releases/v0.4.4-validation.md)。
