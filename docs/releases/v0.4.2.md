# Meetily 0.4.2 — Windows x64

社区构建，2026-09-14。

包括中文优先 SenseVoice、本地/API 摘要、文本修订与来源回查、后台摘要恢复、人工编辑保留生成原稿、收纳式帮助提示，以及本分支的手动发布入口。

下载安装 `Meetily-0.4.2-windows-x64-setup.exe`。安装包自带 WebView2、VC++、ONNX/sherpa 运行库和辅助程序；不需要开发工具。首次启动仍需在准备页下载所选模型。模型、个人会议和 API 密钥不在安装包中。

本构建未使用 Authenticode 发布者签名，Windows 可能显示未知发布者。请核对同版 SHA256SUMS.txt。仓库为私有时下载需具备 GitHub 访问权限。

已知限制：本地摘要仍可能存在事实关系错误；不能将无标识发言对应到姓名；未对其他操作系统或所有硬件组合验收。原文和重要事项需人工复核。

本版验证结果见 [验收记录](validation.md)：前端 281 项、Rust 824 项测试通过；安装包完整性和运行库检查通过，安装后界面验收未完成。来源：当前开发工作区的完整生产源码和回归测试快照，不携带本机历史调试数据。
