# hhu122392/Meetily 社区发行规则

本仓库是独立的 MIT 开源派生版本。保留原作者版权，不代表 Zackriya Solutions 官方发布，也不包含其商业版本授权。

本次 Windows 0.4.3 构建没有 Authenticode 发布者签名，发布页面必须明确这一点并附 SHA-256；不能标为已签名或免 SmartScreen 提示。原 docs/i18n/phase-5a4 策略绑定原公司的 DigiCert 身份，保留用于历史说明，不能用于冒签本仓库构建。默认构建已移除该公司的签名命令。

本仓库已设为公开仓库，无需登录即可浏览源码和下载 Release 附件。自动更新暂不启用：关于页和托盘的版本入口打开本仓库 Releases，不从原项目安装其他版本。后续启用自动更新必须使用本仓库维护者管理的签名密钥及已验证发布渠道。

发布前必须校验源码与版本对应、运行库完整、安装与启动可用、文件无密钥或个人会议数据。安装包可离线安装，模型首次在准备页联网下载；模型准备完成后可本地转录和摘要。不得宣传无需下载模型、已通过所有摘要事实测试或能可靠识别人名。
