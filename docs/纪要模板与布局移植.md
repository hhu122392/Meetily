## 使用入口

在“设置 → 纪要 → 管理纪要模板”进入模板库，也可从会议的模板选择菜单打开管理弹窗；会议页面继续挂载，保留当前编辑内容。支持创建、查看、复制、编辑、删除、设置默认模板、JSON 导入与原生文件对话框导出。

模板编辑按章节填写标题、生成要求、段落或列表格式、必需章节和空内容处理方式，可调整章节顺序。内置模板只读，复制后编辑。导入始终创建新副本，避免覆盖已有会议引用的模板。

会议详情可切换纪要、转写、并排视图；并排视图保留鼠标和键盘调整比例。窄窗口下并排模式显示纪要，并提供转写切换。切换只隐藏面板，不卸载编辑器。正文居中，底部悬浮操作栏继续提供保存、复制、生成、语言与 Lark 入口。

## 数据兼容与隔离

- 内置英文模板继续使用旧标识，例如 `standard_meeting`；中文版本使用 `standard_meeting_zh_cn`，不改变原会议已保存的标识。
- 新公司和未设置默认模板的公司，默认使用中文标准会议模板。已保存的会议设置不随默认模板变化。
- 自定义模板及默认选择存放在当前公司数据目录的 `summary-templates` 中。
- 原公司独占读取旧的 `%APPDATA%/Meetily/templates` 目录；新公司不回退到该目录。旧 JSON 只在内存中转换，原文件保留。
- 删除使用公司目录下的标记，保留模板原文件；内置模板、默认模板及被会议设置引用的模板不能直接删除。
- 保存采用临时文件与原子替换，并检查版本，旧编辑窗口不能覆盖新版本。损坏模板会在库中显示提示，生成时不会静默换用其他模板。
- 默认模板设置损坏时明确报错；不能通过重新读取会议悄悄覆盖为其他默认值。
- 模板保存、导入限制文件体积、字段长度与章节数量，拒绝非法文件名、路径穿越、重复章节和未知版本。
- 保留会议背景、出席/缺席人员及主持人设置。继续使用现有 `summary_request_snapshots` 固定本次模板和会议信息，不新增一套生成历史系统。
- 模板空内容策略转换为生成指令；具体输出仍需要模型遵循指令，并经人工审核。

## 保留的定制能力

人工审核、Lark 原群关联、消息预览与确认、概要卡片、Markdown 附件、Markdown 文件编辑与历史恢复均沿用现有实现。标准会议模板行动项为负责人、任务、截止时间三列；旧会议已生成的正文不做批量重写。
